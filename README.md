# Cathedral of Tristram

Mobile-landscape browser homage to Diablo 1 (v1.09 rules). TypeScript + Vite + Canvas 2D.

- `npm run dev` / `npm test` / `npm run build`
- `?class=warrior|rogue|sorcerer` picks the class (class select screen comes later).
- Data tables with sources: `src/data/` (`[TEMP]` marks unconfirmed values).
